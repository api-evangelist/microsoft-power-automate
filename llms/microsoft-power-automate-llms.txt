# Microsoft Power Automate

> Microsoft Power Automate is a cloud-based service for building automated workflows between apps and services — automated, instant, and scheduled cloud flows plus desktop flows for robotic process automation (RPA). The Power Automate Management API (https://api.flow.microsoft.com, Microsoft.ProcessSimple provider) programmatically manages flows, environments, connections, connectors, and flow permissions, authenticated with Microsoft Entra ID (Azure AD) OAuth 2.0.

This llms.txt was generated by API Evangelist from the catalog entry and repo artifacts; the provider does not publish a machine llms.txt (powerautomate.microsoft.com/llms.txt returns marketing HTML).

## APIs

- [Power Automate Management API](https://learn.microsoft.com/en-us/power-automate/web-api): REST API to create, update, delete, and manage cloud flows, environments, connections, connectors, and flow permissions. Base URL https://api.flow.microsoft.com.
